# Fit research

A one-page site for Heidi's independent user research on how people shop for clothes online and judge fit.

Visitors paste a link to something they're unsure about, and "Text it to me" opens their messages app with the link ready to send. The About view (`#about`) explains the research.

It's a single static `index.html` with no build step. To publish it, turn on GitHub Pages in Settings → Pages and choose the `main` branch.

## Fit Notes demo

`fit-notes-demo/` is a clickable demo of Fit Notes: paste a link to clothes you're eyeing and a link to a piece that fits you well, and get honest, size-by-size fit notes. Sign-in and measurements are simulated, and everything is saved only in the visitor's browser. With GitHub Pages on, it's served at `/fit-notes-demo/`.
